# IoT Monitoring Dashboard

## Requirements

- Node.js 24 LTS (recommended); Vite also supports `^20.19.0 || >=22.12.0`
- npm

The `.nvmrc` file selects the latest available Node.js 24 release when using
nvm. Other Node version managers may require their own version-file format.

## Run locally

```sh
npm ci
npm run dev
```

## Verify

```sh
npm run build
npm run lint
```
